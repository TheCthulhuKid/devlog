## Decisions

- Bake-off schema validity started as a computed `report is not None`, so every failed run counted as a schema failure. It became three-valued: True if a report came back, False only on the shared `InvalidReport` error, and None for run limits, timeouts, API errors, and cut-off or refused replies (`IncompleteReport`). The rate skips the None runs, because they never produced a whole report to judge. ([9159729](https://github.com/TheCthulhuKid/bake-off/commit/915972969e1d76bdf5ab71d28471219fffedc606), [1c39432](https://github.com/TheCthulhuKid/bake-off/commit/1c3943244d39e2db4fa2690f06120958ff83788f))
- Bake-off telemetry first kept the run deadline in a pydantic PrivateAttr on RunStats. It was moved to its own ContextVar beside the stats so RunStats stays plain data that loads back from a results file unchanged, and so code running in a copied context can see both. ([47f360f](https://github.com/TheCthulhuKid/bake-off/commit/47f360fb348b1650d99d8e175164eeee646fc061))
- In bake-off's derived fixtures, seeded duplicates are hand-rewritten to describe the same problem as a second reporter would, instead of being copies, because a copy would only test string matching. Translations are also written by hand, because building fixtures calls no model. ([9b44352](https://github.com/TheCthulhuKid/bake-off/commit/9b44352aa630bc6052729223b799ef9d492478fc), [6bd54b1](https://github.com/TheCthulhuKid/bake-off/commit/6bd54b1e8afeac3a574dc333cab9c8197527456d))
- bake-off: introduced run limits again, to ensure fairness and to stop a run that hangs. ([a4c6c84](https://github.com/TheCthulhuKid/bake-off/commit/a4c6c84ff93bf9ea549adf835a085c532aa8c02b))
- bake-off: the judge is cached, mainly so that a rerun gives the same score. ([b0f12d7](https://github.com/TheCthulhuKid/bake-off/commit/b0f12d751a07f169790da2965d088cafde70995d))

## Dead ends

- Bake-off report: the first version left timed-out runs out of the cost-per-run mean, because PydanticAI and LangGraph recorded tokens only when a run ended and so understated the cost of abandoned runs. That workaround was dropped once every implementation recorded usage as each reply arrived. Cost now includes failed and timed-out runs, priced up to the last finished reply. ([c628877](https://github.com/TheCthulhuKid/bake-off/commit/c6288778d413c3958a880836071fc0393c0323a8), [2a24777](https://github.com/TheCthulhuKid/bake-off/commit/2a24777f1ff8a631342431a0ab4d00adc07dfa0c), [3f07edc](https://github.com/TheCthulhuKid/bake-off/commit/3f07edcee2693cc7016087cdf823541bad46d951))
